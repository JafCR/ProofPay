# ProofPay

An autonomous procurement agent that hires a real, licensed business, escrows the money, and pays only against proof verified in a public registry. It can say no.

Built for the All Things Agentic Hackathon (Taskmaster category).

> Status: bootstrap. Spec at `docs/SPEC.md`.

## Disclosure

All agent code in this repository was created during the hackathon submission period (Aug 2026). It consumes [Pacta Protocol](https://github.com/Pacta-Protocol) (MIT, pre-existing open source by the same author) as its marketplace and MCP tool layer, without modification. The product runtime uses Gemini exclusively.
